# Meta models and partner tools, and where each is used

Draft by D, Sun Nov 1; updated Tue Nov 3 to the production flags at the freeze. `docs/readme-final.md` has a shorter table in the
README's own words; the facts in the two must agree. "Off" means built on `main` behind a flag that is off in production.

| Tool | What it does in Preflight | Where in the code | Today |
| --- | --- | --- | --- |
| **Muse Spark** (`muse-spark-1.3`, Meta Model API) | Reads each script with structured output (the script map) | `python/preflight/harness/mapper.py` | On in production |
| | The guide: tool calls on the live cockpit through the Responses API | `api/preflight_api/guide/` | On in production (`c.guide.live`) |
| | The diagnosis: reads a finished record's memory timeline and loss plot as images, with the raw probe numbers, and reports where they disagree, each claim number-checked | `python/preflight/harness/diagnosis.py` | On in production (`harness.spark_diagnosis`, Nov 2); never for a record a private check-in touched |
| | Search grounding on a failed probe: searches the web for a known library or version issue and cites at most 3 sources, kept only if a search returned them | `python/preflight/harness/search_grounding.py` | On in production (`harness.spark_search`, Chiya, Nov 3) |
| | The model inside the agent evaluation Preflight measured (130 tasks) | `zoo/agent_eval_spark/` | Measured runs, Oct 31 and Nov 1 |
| **Muse Code** (headless) | The fix loop: candidate fixes written in sandboxes, edits only, each gated on Preflight's re-probe, never on Muse Code's exit code | `api/preflight_api/fix/`, `api/fix_app.py` | On in production (`c.fix_loop`, Nov 2). On the LoRA sample's eval out-of-memory, verify rejected the single fix and passed the stacked fix at eval batch 8 (eval peak 10.4 GiB, loss within 0.11%; US$0.39 at list price) |
| **Muse Spark Open** (`meta-models/muse-spark-open-1026`, Baseten) | Triage of each probe's log: a category, one sentence, and a quoted log line that code checks | `python/preflight/harness/triage.py` | On in production (`harness.spark_open_triage`); first real run `a-triage-lora-prod`, 4 calls, US$0.0184; quoted a line on all 11 failed zoo probes (`a-triage-agreement`) |
| | The number check (claim check): code finds the record fields each number in a model-written finding could mean; Spark Open picks among them | `python/preflight/harness/claim_check.py` | On in production (`harness.spark_claim_check`, Nov 2); on planted claims, true numbers passed 101 of 107 and altered ones were caught 93 of 102 |
| **Muse Glimmer** (open weights, Apache 2.0) | Private mode: triage of a private job's failed probes on Preflight's own GPU; also a row in the agent model sweep | `python/preflight/glimmer/`, `python/preflight/runner/pipeline.py`, `docs/decisions/glimmer-host.md` | On in production since Nov 2 (`harness.glimmer_private`): a check-in with "Private triage" ticked; hosted on an A100-40GB on Modal that Preflight deploys, scaled to zero; US$0.24 for one call through a 411 s cold start, US$0.33 for 11 calls in one run (likely one cold start among them); same category as Spark Open on 9 of 11 failed zoo probes |
| **Modal** | GPU sandboxes for probes, the job store and API, the corpus sweep, the fix loop's sandboxes | `python/preflight/runner/`, `api/`, `python/preflight/corpus/` | Every NVIDIA measured run; the AMD runs were on a rented MI300X on RunPod; the runner, the API and the fix app are deployed in production |
| **Baseten** | Hosts Muse Spark Open | `python/preflight/harness/spark.py` | Used by triage, on in production |
| **AMD Developer Cloud** | ROCm probes on an MI300X through the CLI, and the AMD half of the corpus | `.github/workflows/amd-run.yml`, `python/preflight/corpus/` | The account stayed on a verification hold, so the AMD runs used a rented MI300X on RunPod (Nov 2): probes and full runs of two zoo scripts (same-GPU step time 2 of 2 within 15%, the LoRA eval OOM caught) and 295 corpus configs (NVIDIA to MI300X step time: 22% within 20% (NVIDIA torch 2.8.0 to MI300X torch 2.5.1+rocm6.2: card and software differ), 254 of 1,147 pairs, so a move across vendors abstains) |
| **Cloudflare Pages** | The web app, the `/v1` edge proxy, and share cards | `web/`, `web/functions/`, `workers/` | Live at https://preflight-cqn.pages.dev, with share pages and badges (`/s/<share token>`) |
